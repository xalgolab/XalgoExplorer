# xAlgo Explorer v0.2.0-candidate

## 候选版说明 / Prerelease

本版本用于原生界面重构验收，不是稳定版。使用本机 ad-hoc 签名，尚未进行 Developer ID 签名或 Apple 公证。请先使用临时文件进行验证，并备份重要数据。

This is a testing prerelease, not a stable release. The app is ad-hoc signed and is not Developer ID signed or Apple notarized. Validate with disposable files first and back up important data.

## 下载与兼容性 / Assets and Compatibility

- Platform: Apple Silicon (arm64).
- Minimum OS: macOS 14; Liquid Glass uses Apple's system API on macOS 26 or later.
- Earlier supported systems use native material instead of simulated glass.
- Installer: `xAlgo_Explorer_v0.2.0-candidate_aarch64.dmg`.
- Checksum: `xAlgo_Explorer_v0.2.0-candidate_aarch64.dmg.sha256`.
- SHA-256: `865829a92ea751eab25aa6370bb984274cd5e4eeedd8d377c7bb0f13db786300`.

Download the DMG and checksum into the same directory, then verify:

```sh
shasum -a 256 -c xAlgo_Explorer_v0.2.0-candidate_aarch64.dmg.sha256
```

## 已验证 / Validation

- `swift test`: 96 XCTest tests passed, 0 failures.
- Release build and DMG packaging passed.
- App bundle signature, disk image integrity, and SHA-256 verified.
- Tested on Apple Silicon with macOS 27, Xcode 27, and Swift 6.4.
- Native UI checks: single/three-pane layout, independent main-pane navigation, search input and Escape dismissal, focus after view switching, arrow-key and Shift selection scrolling, icon navigation, file context menus, and copy/paste through the destination's blank-area menu.

## 未完成验收 / Validation Limits

- 自动化原生拖放会话未完成落点；隐藏侧栏拖入创建快捷方式、长距离拖动圈选和真实跨卷拖放仍需人工验证。取消后原文件保持不变，业务层拖拽规则和旧 payload 隔离已有回归测试。
- 尚未在 macOS 14/15/26 实机验证，也未完成浅色、高对比度及减少动态效果的完整视觉验收。
- 网络页显示空状态，尚未实现真实网络设备发现。
- Automated native drag sessions did not complete their destination drop. Real-mouse sidebar shortcut drops, long-distance drag selection, and real cross-volume drops still require manual validation. Cancellation preserved the test files; model-level drag rules and stale-payload isolation have regression coverage.
- macOS 14/15/26, light appearance, high contrast, and reduced-motion behavior have not completed hardware/visual validation.
- The network page is an empty state; actual network-device discovery is not implemented.
